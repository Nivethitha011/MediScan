# MediScan

**Scan. Understand. Remember.**

MediScan is an AI-powered medicine information assistant that uses Optical Character Recognition (OCR) and a Large Language Model (LLM) to extract and explain information from medicine packages.

## Overview

MediScan allows users to upload an image of a medicine strip or capture one using their camera. The application extracts the text using Tesseract OCR and then uses Hugging Face AI to identify and organize important medicine information in a simple format.

## Features

* Upload medicine strip images
* Capture medicine images using the camera
* Extract medicine text using Tesseract OCR
* Identify medicine name
* Identify active ingredients
* Identify medicine strength
* Explain common uses
* Display possible side effects
* Provide important precautions
* Provide food-related information when available
* Generate a general health tip
* Simple and user-friendly Streamlit interface

## How It Works

```text
Medicine Image
      |
      v
Tesseract OCR
      |
      v
Extracted Text
      |
      v
Hugging Face LLM
      |
      v
Medicine Information
      |
      v
User-Friendly Display
```

## Installation

Clone the repository:

bash
git clone https://github.com/nivethitha011/MediScan.git


Navigate to the project directory:

bash
cd MediScan


Install the required packages:

bash
pip install -r requirements.txt


Make sure Tesseract OCR is installed on your system.

## Environment Setup

Create a `.env` file in the project directory:

env
HF_TOKEN=your_huggingface_token


Do not share or upload the `.env` file to GitHub.

## Run the Application

Run the Streamlit application using:

bash
python -m streamlit run app.py


The application will open in your browser.

## Safety Notice

MediScan is designed for educational and informational purposes. The information generated by the application should not replace advice from a doctor, pharmacist, prescription, or official medicine leaflet.

Users should verify medicine information with a qualified healthcare professional before making decisions about medication.
